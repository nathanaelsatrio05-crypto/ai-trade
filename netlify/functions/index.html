🔑 API Key Setup
Server-side

API key disimpan aman di server Netlify — tidak terekspos di browser.

Cara setup di Netlify:

1. Buka app.netlify.com
2. Pilih site kamu → Site Settings
3. Klik Environment Variables
4. Add variable:
  Key: ANTHROPIC_API_KEY
  Value: sk-ant-api03-xxxx...
5. Redeploy site kamu

Belum punya API key? Daftar di console.anthropic.com
